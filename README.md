## Featured Project

### DataQuery Agent

**AI data-analysis Agent for business users**

一个面向商业地产运营场景的可审计 AI 问数产品探索。项目聚焦传统 Text-to-SQL 容易忽略的产品风险：指标口径歧义、模型静默猜测、过度干预，以及缺少可追溯证据。

**Product work**

- Defined the target user, business scenario and product boundaries
- Designed an `execute / disclose / clarify / reject` decision workflow
- Built a Semantic Gate that keeps final execution authority in deterministic code
- Designed frozen evaluation sets, Bad Case analysis and iteration criteria
- Developed a Streamlit prototype with inspectable decision traces

**Current evidence**

- Phase 9C offline mechanism completed
- 123/123 current automated tests passed
- Phase 9B v2 development smoke: 28 cases and 40 real-model calls
- Failed cases are retained and used to drive product iteration
- No claim of production readiness, generalized accuracy or validated business impact
